# NERDS Autonomous Web Director (Proprietary Engine)

NERDS turns Antigravity IDE into a high-performance, autonomous web engineering system built on two non-negotiable core values: **NERDS Custom Design Intelligence** and **NERDS Native 5-Role Pipeline**.

---

## 🏛️ Core Value 1: NERDS Custom Design Intelligence Engine

Every web application built or edited by NERDS MUST follow the proprietary **NERDS Anti-Slop Design System**:

### 🚫 Anti-Slop Bans (Strict Enforcement)
- **NO Generic Glassmorphism**: Forbid low-contrast translucent cards with heavy backdrop blurs.
- **NO AI-Sloppy Gradients**: Forbid overused purple/blue radial blur background spots.
- **NO Default Hero Section Templates**: Every hero section must be bespoke and domain-tailored.
- **NO Unstyled Browser Fonts**: Must use system-ui / Inter font stacks with fluid clamp sizing.

### ✅ Enforced Design Standards
1. **Obsidian HSL Color Tokens**:
   - `--bg-base`: `hsl(222, 24%, 9%)`
   - `--bg-surface`: `hsl(222, 20%, 13%)`
   - `--accent-primary`: `hsl(212, 100%, 62%)`
2. **Fluid Clamp Typography**: `font-size: clamp(1rem, 0.95rem + 0.25vw, 1.0625rem)`
3. **Accessibility**: Strict WCAG AA contrast ratio compliance on all text and interactive elements.
4. **Zero Cumulative Layout Shift (CLS)**: Dynamic skeleton loading states for async data.

## 🧠 Core Value 2: NERDS Native 5-Role Sprint Pipeline

Every task executed by NERDS MUST pass through our native 5-role quality gate:

1. **👔 Product CEO Role**:
   - Validates problem statement, issue scope, and user story requirements.
2. **📐 Architect EM Role**:
   - Plans modular file boundaries (`src/core`, `src/components`, `src/features`), isolating interfaces to prevent partner collisions.
3. **🎨 Lead Designer Role**:
   - Applies the NERDS Custom Design Intelligence engine tokens, typography, and micro-interactions.
4. **🧪 QA Lead Role**:
   - Executes build/lint checks and launches Antigravity's `browser_subagent` to render pages, click interactive buttons, and capture visual proof screenshots/recordings.
5. **🛡️ Security Auditor Role**:
   - Scans code changes via `scripts/security-leak-scanner.js` for hardcoded API keys, exposed tokens, or OWASP vulnerabilities.

## 🛠️ Configurable Modules (On-Demand Setup)

When initialized via `npx nerds init`:
* **GitHub Pro Manager (Optional)**: If enabled, polls issues matching `assignedLabel` from `.nerds.json`, executes atomic micro-commits, and creates PRs via `gh` CLI.
* **Cross-LLM Partner Sync (Optional)**: If team members > 0 (max 4), synchronizes lock state on `sync/llm-coordination` orphan branch.

## 💬 Chatbox-Native Reporting Protocol
NERDS delivers all GStack role logs, atomic commit hashes, diff summaries, and `browser_subagent` visual proof directly into your **LLM Chatbox** and markdown walkthrough artifacts (`walkthrough.md`).
